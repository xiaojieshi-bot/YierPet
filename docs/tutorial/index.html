    桌面上会出现「一二」。程序坞里没有图标是正常的。

1. 这是什么

YierPet（一二桌宠）是一只住在 macOS 桌面上的透明悬浮小宠物。 它会自己散步、跳跃、挥手；可以拖拽和「甩出去」玩物理抛掷； 还会在合适的时候用头顶气泡提醒你喝水、起身、别熬夜，并在 CPU 飙高时「红温」。

应用以无 Dock 图标的方式运行（不占程序坞位置）， 也不需要辅助功能、屏幕录制等敏感权限。

2. 开始之前

  • 操作系统：macOS 13（Ventura）或更高版本。
  • 命令行工具：需要已安装 Xcode Command Line Tools（用于编译 Swift）。

若尚未安装，打开「终端」，执行：

xcode-select --install

在弹窗中按提示安装，通常几分钟即可完成。

不需要从 App Store 安装完整版 Xcode，也没有第三方依赖包。

3. 安装与首次启动

在终端中依次执行以下命令（可复制粘贴）：

git clone https://github.com/xiaojieshi-bot/YierPet.git
cd YierPet
./build.sh
open build/YierPet.app

各步说明

  1. git clone … — 从 GitHub 下载项目源码。
  2. cd YierPet — 进入项目目录。
  3. ./build.sh — 编译并生成 build/YierPet.app。
  4. open build/YierPet.app — 启动桌宠。

成功后，桌面上会出现「一二」，并开始随机走动。程序坞里不会出现图标，这是正常现象。

4. 无法打开？（Gatekeeper）

若你使用的是别人打包好的 .app（不是在本机执行 ./build.sh 构建的），macOS 可能提示「无法打开」或「来自身份不明的开发者」。

解决办法：

  1. 在 Finder 中找到 YierPet.app；
  2. 按住 Control 键并点击（或右键）应用图标；
  3. 选择「打开」；
  4. 在对话框中再次点「打开」。
在本仓库目录下自行 ./build.sh 构建的应用，一般不会出现此问题。

5. 开机自启（可选）

  1. 打开「系统设置」→「通用」→「登录项」（或「登录时打开的项目」）；
  2. 点击「+」或「添加」；
  3. 选中你构建好的 build/YierPet.app（建议放在固定位置，例如「应用程序」文件夹）；
  4. 确认添加。

下次登录 macOS 后，一二会自动出现在桌面。

操作效果

7. 右键菜单

在宠物身上右键，可看到：

  • 形象 — 切换四种外观（选择会自动保存）；
  • 动作 — 仅「经典一二」可用，手动切换 9 种图集动作；
  • 暂停随机行为 / 开启随机行为 — 控制是否自动散步、跳跃等；
  • 提醒设置 — 久坐、喝水、深夜、摸鱼检测的开关；
  • 系统哨兵 — CPU、内存、电量、磁盘等系统提醒开关；
  • 陪伴模式 — 早晨问候、午饭、下午茶、周五、编码久战等节律提醒；
  • 退出 — 关闭应用（快捷键菜单项为 Q）。
隐藏功能：按住 Option 再右键，会出现「测试提醒」子菜单，可立即触发各类提醒，方便演示或检查效果。

8. 健康提醒与系统哨兵（概要）

健康提醒

类型大致触发条件
久坐提醒连续在电脑前活跃约 1 小时（离开 5 分钟会清零）
喝水提醒约每 30 分钟（人不在时不计时）
深夜关怀23 点后进入「睡意」；若仍在工作，约每 30 分钟关怀一次
摸鱼检测视频类 App 连续前台约 30 分钟（B 站、腾讯视频、IINA 等）

系统哨兵

平时不打扰，仅在异常时冒气泡，例如 CPU 持续偏高、内存压力 critical、低电量、磁盘空间不足等。CPU 红温时经典版会逐渐变红；「活力一二」表情包有全身着火动画。

任意两类提醒之间有约 90 秒 的全局间隔，避免连环刷屏。各项均可在菜单中单独关闭。

11. 常见问题

程序坞里找不到 YierPet？

设计如此。请右键宠物 →「退出」来关闭应用。

需要授权辅助功能或屏幕录制吗？

不需要。活跃与前台 App 检测使用系统公开 API。

摸鱼检测认不出我用的播放器？

可在源码 ActivityMonitor.swift 的 slackBundleIDs 中加入该 App 的 Bundle ID。终端查询示例：

osascript -e 'id of app "应用名称"'

想改台词或提醒间隔？

文案与阈值在 ReminderCenter.swift；手感参数在 PetController.swift。修改后重新执行 ./build.sh 即可。

12. 如何退出

右键点击桌面上的宠物 → 选择退出。

不要指望从程序坞或「强制退出」列表里找图标——本应用故意不显示在 Dock 中。
